# DATA-CLASSIFICATION — daggerfall-bevy-native

Version 1.1 · 2026-10-21 · see also [CONTRIBUTING.md](CONTRIBUTING.md) for the rules a change must
follow and [Data, legal and trademarks](docs/acknowledgments/legal-and-trademarks.md) for the licence.

## 1. Own code (git-tracked)

The only committable material:

- Rust sources of every crate (`crates/**/src/`).
- Cargo manifests (`Cargo.toml`, `Cargo.lock`).
- Project documentation: `README.md`, `ARCHITECTURE.md`, `CONTRIBUTING.md`, `DATA-CLASSIFICATION.md`,
  `docs/**` and the language policy under `docs/i18n/`.
- Registries and guardrails: `ASSET-REGISTRY.json`, `.gitignore`.

## 2. Bethesda data (runtime-only — NEVER in git)

- **What:** Daggerfall game files (GOG build 1.07): `*.BSA` (ARCH3D, MAPS, BLOCKS, MONSTER, MIDI),
  `*.QBN`/`*.QRC`, `TEXTURE.*`, the original DOS executables and drivers, DOSBox.
- **Where it lives:** in the player's own installation, outside the repository tree — by default under
  `$DF_APP_ROOT`, with the archives in its `ARENA2/` directory. Any absolute path of a development
  machine is machine-specific and is not published here.
- **Licence:** Bethesda freeware (2009). Local use; **no redistribution** — the bytes are never
  packaged or copied into the repository.
- **Guardrails:** `.gitignore` (`data/`, `ARENA2/`, `arena2/`, `*.BSA`, `*.VID`, `*.pal`, `target/`) plus
  mandatory negative verification (`git ls-files` with none of those extensions; 0 Bethesda bytes in
  the repository), and an antibody in `scripts/ci/` that rejects a packaged `.BSA`.

## 3. Own generated assets

Sprites, textures and audio generated by the project (own licence). Git-tracked by default; if an
artifact is heavy enough to need a different rule, its classification is decided when it is first
added and documented here.

## 4. Build artifacts and runtime state (git-ignored)

`target/` (cargo), binaries and compilation profiles.

`saves/` is **runtime state**, not tracked material: the engine writes `saves/session.dfs` when a
session is saved (own data, 468 B). It is ignored and untracked; probes write to `TMPDIR`, so no probe
depends on a versioned save.

## 5. Negative verification

- `git ls-files` → 0 `.BSA` / `.VID` / `.pal` files.
- 0 Bethesda bytes inside the repository: the BSA files and the rest of the game live exclusively in
  the player's own installation; the hash registry is in `ASSET-REGISTRY.json`.
